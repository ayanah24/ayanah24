## 🚀 Featured Projects  

### 🤖 [CodeSense AI – AI-Powered Automated Code Review & Security Gatekeeper](https://codesense-ai.duckdns.org) *(Flagship Project)*
A full-stack, production-deployed platform that automates GitHub Pull Request reviews using Agentic AI, Pinecone RAG codebase context, and CI/CD security gating.  

🌐 **Live App:** [codesense-ai.duckdns.org](https://codesense-ai.duckdns.org) | 💻 **GitHub Repository:** [github.com/ayanah24/CodeSense-AI](https://github.com/ayanah24/CodeSense-AI)  

**Tech Stack:** React 19 | Vite | Express 5 | BullMQ | Redis 7 | MongoDB | Pinecone Vector DB | Google Gemini AI | LangGraph | Socket.io | Docker | AWS EC2 | Nginx  

**Key Engineering Highlights:**  
- **Automated Webhook Pipeline:** Real-time GitHub webhook handling with HMAC SHA-256 verification and automatic webhook creation/cleanup via API.  
- **Pinecone RAG & LangGraph AI:** Multistage state graph retrieving vector embeddings from Pinecone to feed codebase context to Google Gemini for deep code analysis.  
- **Asynchronous Background Processing:** Decoupled architecture using BullMQ and Redis to process pull request diffs without blocking HTTP requests.  
- **Inline PR Reviews & Merge Gates:** Automatically posts line-by-line comments on GitHub PRs and updates GitHub Commit Pass/Fail Status checks.  
- **Headless CI/CD API & API Keys:** Cryptographic API Key engine (`csk_live_...`) hashed with SHA-256 at rest, enabling execution from GitHub Actions, GitLab CI, or Jenkins.  
- **Real-Time UI & Monaco Editor:** Instant frontend refreshes via Socket.io and embedded Monaco code editor for manual snippet reviews.
